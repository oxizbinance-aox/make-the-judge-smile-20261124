One line, at most 200 characters, about a small good thing that happened today — something that would make a reader smile.

> This morning the bus driver held the door open while an old man shuffled across with his groceries, and the whole bus waited, nobody honked, nobody sighed.

`main.ts` (Node 22) writes the line deterministically to `/output/entry.txt` — the same bytes on every run, with a built-in gate self-check (1–200 characters, not whitespace-only).
